### ✏️ Description

Furnix is a sleek, modern e-commerce website for showcasing and selling products. Built with React and Tailwind CSS, it offers a fast, responsive experience, complete with product filtering, a dynamic cart, and fake backend support using JSON Server.

---

## 🚀 Features

- ⚛️ **React** for a fast and modular front-end
- 🎨 **Tailwind CSS** for modern, responsive styling
- 🧠 **Redux Toolkit** for global state management (cart, products, favorite products)
- 🔌 **JSON Server** to simulate a RESTful API backend
- 🛍️ Add to Cart, Remove from Cart, and Quantity Update functionality
- 🔍 Product Filtering & Searching
- 📱 Fully responsive design (mobile-first)

## ⚙️ Getting Started

### 1. Clone the Repository
   ```bash
   git clone https://github.com/MohsenAbediDev/Furnix.git
   ```
### 2. Navigate to the project directory
   ```bash
   cd Furnix
   ```
### 3. Install dependencies
   ```bash
   npm install
   ```
### 4. Start JSON Server
   ```bash
   npm run server
   ```
This runs JSON Server at http://localhost:3000/ with mock data in db.json.

### 5. Run the App
   ```bash
   npm run start-dev
   ```
App will be available at http://localhost:5173/Furnix/.
